## 4. Issues and Limitations

1. **Provenance требований = `snapshot`.** Прямой Confluence READ через Tool недоступен: `tools.jira.fetch` для Confluence-ARI возвращает `401 Unauthorized; scope does not match` (у токена только `read:jira-work`, `write:jira-work`); Rovo-поиск пуст. Требования получены Orchestrator через Confluence REST API v2 (`/wiki/api/v2/pages/2228225?body-format=storage`) и переданы агенту как snapshot. Оформление, макросы, вложения, комментарии и колонтитулы страницы не проверялись. `related_requirements` (parentId 131165, дочерние страницы) не передавались.
2. **Fidelity-оговорка BR-01.** В storage-формате после перечней специальных символов стоит одиночный символ «`»; его принадлежность перечню по snapshot не определяется. Символ в перечни не включён.
3. **Текст сообщения при нарушении формата не зафиксирован** (NB-14 / OQ-05): по решению BLK-04 сообщение одно общее, но его текст не задан. В Jira AC и в Qase Expected Result проверяется факт отображения сообщения и отсутствие отправки, конкретная строка не утверждается. Для нарушения белого списка символов пароля текст сообщения также не задан → REQ-25 покрыт `PARTIAL`.
4. **`PARTIAL`-покрытие:** REQ-25 (текст/наличие сообщения при нарушении символов пароля) и REQ-33 (границы «текущего профиля браузера», NB-02). Оба требования имеют `READY`-тест-кейсы на наблюдаемую часть.
5. **Приоритет Jira-задач `UNDEFINED`** — ни требования, ни проектные правила приоритетов не задают. Требуется внешнее решение, если приоритет нужен.
6. **Нефункциональные пробелы не превращены в требования:** защита от перебора (NB-09), время жизни неактивной сессии (NB-10), браузеры/производительность (NB-12), выход из системы (NB-05) — задачи и тест-кейсы не создавались.
7. **Отказ сервиса авторизации** (NF-12) выведен из области требований решением BLK-05: задачи и тест-кейсы не создавались.
8. **Ограничение инструмента Qase:** `qql_search` по `AUTH` на момент завершения этапа возвращал `total = 0` при фактических 37 кейсах (задержка индекса). Проверка Orchestrator выполнена через тот же `qql_search` (37 записей) и `qase_get` по разделам 12 … 18 — расхождение на момент проверки отсутствует.
9. **MCP-endpoint Atlassian:** сервер Jira работает через устаревший `/v1/mcp` (отключение 2027-03-01). Требуется миграция конфигурации на `https://mcp.atlassian.com/v2/mcp` (см. migration guide Atlassian). Не влияет на результат текущего прогона.
10. Дубликаты: в Jira до создания была только KAN-52 («Эпик», без описания) — не сопоставима с функциональностью; в Qase проект был пуст. Дубликаты не созданы.
